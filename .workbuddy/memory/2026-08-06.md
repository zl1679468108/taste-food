## 小程序提交订单 10s 超时诊断与修复
- **现象**：小程序模拟器提交外卖订单时 `POST /api/orders` 10s 后被取消，提示「网络连接失败」；Network 面板显示其他接口均 200，仅 `orders` 请求 10.00s (cancelled)。
- **排查结论**：
  - 后端 `3010` 端口监听正常，本机 `curl 192.168.0.112:3010/api/orders` 可通，排除网络层问题。
  - 后端 `server/src/common/utils/tencent-map.ts` 中 `geocodeAddress` / `fetchStaticMapImage` 的 `fetch` **无超时**；若腾讯地图 API 响应慢，会导致订单创建链路挂起直至小程序端 10s 超时。
  - 当前 `TENCENT_MAP_KEY`（`server/.env.development`）已触发 **status=121「每日调用量已达到上限」**。
- **修复**：
  - `server/src/common/utils/tencent-map.ts`：新增 `fetchWithTimeout`（默认 5s），`geocodeAddress` 与 `fetchStaticMapImage` 均改用带超时的 fetch。
  - `server/src/modules/auth/auth.service.ts`：`code2Session` 微信登录 fetch 增加 8s 超时，避免同样问题。
- **验证**：`server npx tsc --noEmit` 0 错；已重启后端（清理 `/tmp/tf-server-3010.pid` 与旧进程后 `npm start`）。
- **后续建议**：若仍下单失败，检查前端收货地址是否带有效经纬度；如长期 geocode 失败，应更换腾讯地图 WebService Key 或在开发环境临时注释 `TENCENT_MAP_KEY`。
