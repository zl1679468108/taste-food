### 修复 socket.io-client 小程序编译错误
- 问题：`socket.io-client` → `engine.io-client` → `xmlhttprequest-ssl` 依赖 Node.js `child_process`，在微信小程序编译时失败
- 解决：
  1. 安装 `@tarojs/plugin-http@4.2.0` — 提供 XMLHttpRequest polyfill (通过 `wx.request`)
  2. 在 `config/index.ts` 的 `webpackChain` 中为 `engine.io-client` 的 ESM/CJS 版本添加 alias，将 `.node.js` 映射到浏览器的 `.js` 版本
  3. 创建 `src/websocket-polyfill.ts` — 基于 `Taro.connectSocket()` 实现标准 WebSocket API
  4. 在 `app.tsx` 入口注入 polyfill: `(globalThis as any).WebSocket = MiniProgramWebSocket`
- 编译后验证：`xmlhttprequest-ssl` 未打包，`MiniProgramWebSocket` 已注入
- 配置注意事项：Taro 不支持 `resolve.fallback`（schema 校验拒绝），仅通过 alias 解决模块映射
